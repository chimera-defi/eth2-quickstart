# CryptoSkill Submission Notes

This directory contains the portable submission payload for publishing `eth2-quickstart`
into a CryptoSkill-style registry.

Included files:
- `SKILL.md`
- `SOURCE.md`
- `_meta.json`

Intent:
- keep the submission payload inside this repo
- do not vendor the full external `cryptoskill` registry clone into this repo

Source of truth:
- the real implementation remains this repository
- the submission payload is only packaging and attribution metadata
