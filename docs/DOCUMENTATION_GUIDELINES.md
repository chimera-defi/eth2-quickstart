# Documentation Guidelines

## File Location
**ALWAYS add documentation files to the `docs/` folder, not the root directory.**

## Documentation Structure
The `docs/` folder contains all project documentation:

### Core Documentation
- `README.md` - Main project overview (in root)
- `SCRIPTS.md` - Detailed script reference
- `WORKFLOW.md` - Setup workflow and process
- `GLOSSARY.md` - Technical terminology

### Configuration & Architecture
- `CONFIGURATION_GUIDE.md` - Configuration architecture
- `REFACTORING_CONFIGS.md` - Configuration refactoring details
- `REFACTORING_SUMMARY.md` - Overall refactoring summary

### Development & Testing
- `SHELL_SCRIPTING_BEST_PRACTICES_AND_LINTING_GUIDE.md` - Shell scripting standards
- `SHELL_SCRIPT_TEST_RESULTS.md` - Test results and validation
- `COMPREHENSIVE_SCRIPT_TESTING_REPORT.md` - Comprehensive testing

### Project Management
- `CONSOLIDATED_PR.md` - Pull request consolidation
- `FINAL_VERIFICATION.md` - Final verification and validation
- `COMMIT_MESSAGES.md` - Commit message conventions
- `progress.md` - Development progress tracking

### Analysis & Reports
- `STREAMLINING_SUMMARY.md` - Streamlining changes summary
- `STREAMLINING_ANALYSIS.md` - Streamlining analysis and redundancy check
- `DOCUMENTATION_GUIDELINES.md` - This file

## Guidelines

### When Creating New Documentation
1. **Always place in `docs/` folder**
2. Use descriptive filenames in UPPERCASE with underscores
3. Follow existing naming conventions
4. Update this list if adding new categories

### File Naming Convention
- Use UPPERCASE with underscores
- Be descriptive and specific
- Examples: `STREAMLINING_SUMMARY.md`, `CONFIGURATION_GUIDE.md`

### Content Guidelines
- Use clear, concise language
- Include overview, details, and examples
- Reference related files when appropriate
- Keep documentation up to date

## Note
This guideline was created after accidentally placing `STREAMLINING_SUMMARY.md` in the root directory instead of the `docs/` folder. All future documentation should be placed in the `docs/` folder to maintain organization and consistency.
