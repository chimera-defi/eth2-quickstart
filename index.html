Quick Start

1

Clone Repository

Download the setup scripts to your server

git clone https://github.com/chimera-defi/eth2-quickstart
cd eth2-quickstart
chmod +x run_1.sh
2

Run Setup

Execute the automated setup script

./run_1.sh
3

Choose Clients

Select your preferred client combination

./select_clients.sh
4

Install & Start

Install clients and start your node

./run_2.sh
